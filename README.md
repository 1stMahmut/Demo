# Rafa Atelier (دار رفا) — demo website

Static demo site for [@rafa_atelier.lb](https://www.instagram.com/rafa_atelier.lb), a handmade modest-fashion atelier in Lebanon.

**Design direction:** Cottagecore (handmade textures, florals, storybook mascot) calmed with Japandi restraint (space, natural palette), plus the brand's own illustrated character, Rafeef, as the guide.

- Arabic-first (RTL) with an English toggle (remembered per browser)
- Sections: hero, collection "rooms" with filters, handmade process, lookbook, "Gentle Talks" journal, how to order
- Ordering through WhatsApp with a pre-filled message per piece

## Run
Open `index.html` in a browser — no build step.

## Before showing it live
- Set the real number in `app.js` → `WHATSAPP_NUMBER` (currently a placeholder)
- Product photos in `img/` are cropped from Instagram screenshots; swap in originals for sharper images
- Product names and descriptions are placeholder copy written in the brand's voice
